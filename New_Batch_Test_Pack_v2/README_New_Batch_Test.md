# New Batch Assessment - Python Foundation

## Exam Overview
- **Batch:** New Batch
- **Duration:** 2.5 hours
- **Expected working time:** about 2 hours, with 30 minutes buffer for review and submission
- **Total questions:** 10
- **Recommended submission format:** Jupyter Notebook (`.ipynb`)
- **Allowed fallback:** `.py` file only if your trainer has explicitly allowed it

## Objective
This assessment checks your understanding of core Python foundation topics covered in the course, including:
- strings and basic text processing
- loops and conditional logic
- lists, tuples, sets, and dictionaries
- functions and lambda usage
- datetime and arithmetic logic
- exception handling
- object-oriented programming and inheritance
- file handling
- CSV processing using the Python standard library

## Important Instructions
